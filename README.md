# Little Niou

Website for the Little Niou coffee cart. Plain HTML and CSS with no build step, hosted on GitHub Pages.

- `index.html`: page content (menu, events, contact)
- `styles.css`: styles
- `favicon.svg`: site icon
- `404.html`: not-found page

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

Pushes to `main` publish automatically to https://icaspkara.github.io/cafeniou-web/.
